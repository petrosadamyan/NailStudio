04 / ABOUT PROJECT

CARCONSTRUCTOR

CarConstructor — индивидуальный школьный проект, посвящённый созданию интерактивного веб-конструктора автомобилей.

Проект разрабатывается с использованием HTML, CSS и JavaScript. Пользователь сможет самостоятельно собрать автомобиль, выбирая различные параметры и компоненты.
